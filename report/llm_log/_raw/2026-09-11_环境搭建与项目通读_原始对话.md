**本轮最重要的发现 —— mediapipe 接口**：

**待用户决定**：mediapipe 走"Python 3.12 + 0.10.21 旧 API"还是"Python 3.14 + Tasks API 重写代码"。

**新暴露的代码问题（已如实上报，未擅自修改）**：

`--source synthetic` 不加 `--stub` 时崩溃 ——

```
[face_landmark] 使用 MediaPipe FaceMesh（478 点）。
cv2.error: OpenCV(4.11.0) ... in function 'cvtColor'
  src is not a numpy array, neither a scalar
```

原因：`capture.SyntheticImage` 不是 numpy 数组（只提供 `shape` 与 `average_luma()`），
而 `MediaPipeLandmarker.detect` 直接对它调 `cv2.cvtColor`。
此前 mediapipe 从未装上过，该路径永远走 stub，所以一直没被发现。
给了两条修法（小改：`face_landmark` 判断非 ndarray 就跳过；大改：让 `SyntheticImage` 产出真 ndarray，
副作用是 `quality.py` 会切到真像素路径、合成 demo 的质量分数会变），**交由 A 线决定**。
