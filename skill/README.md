## 本机使用方式

- `fpga_hls_c_line.md` 是给 AI 助手用的"常驻技能说明":任何 C 线任务开始时,让助手先读该文件再动手。
- 其余条目在对应里程碑完成后,把真实踩坑记录填进去(谁、何时、现象、原因、解法)。

## 规则

- 只记录"验证过"的经验,未验证的写进 `docs/` 待办,不写进 skill。
- 每个 Skill 保留"变更记录",谁改谁签。
