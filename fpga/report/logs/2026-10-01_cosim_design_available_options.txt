SYNTAX 
  cosim_design [OPTIONS]

DESCRIPTION
  Executes post-synthesis co-simulation of the generated RTL with the original C-based testbench.

OPTIONS
  -O
    Enables optimize compilation of the C testbench and RTL wrapper. Without optimization, cosim_design will compile the
    testbench as quickly as possible.
  -argv <string> 
    Option to specify the argument list for the behavioral testbench. The <string> will be passed to the main C function.
  -compiled_library_dir <string> 
    Option to specify the compiled library directory during simulation with 3rd party simulators.
  -coverage
    This option enables the coverage feature during simulation with the VCS simulator.
  -disable_binary_tv
    Use plain text binary test vector files instead of binary compressed format
  -disable_deadlock_detection
    Disables deadlock detection
  -disable_dependency_check
    Disables dependency checks
  -enable_dataflow_profiling
    This option turns on the dataflow channel profiling to track channel sizes during simulation
  -enable_fifo_sizing
    This option turns on auto dataflow FIFO channel size tuning during simulation
  -enable_tasks_with_m_axi
    Enables simulation of "hls::task" and ap_ctrl_none with stable top pointers
  -hwemu_trace_dir <string> 
    Specify hwemu trace test vector file folder
  -ldflags <string> 
    Provides for the specification of options that need to be passed to the linker for co-simulation. This is typically used
    to pass on include path information or library information for the C test bench.
  -mflags <string> *** DEPRECATED***
    Provides for the specification of options that need to be passed to the compiler for systemc simulation. This is
    typically used to speed up compilation.
  -random_stall
    Enable random stalling of top level interfaces during co-simulation
  -rtl <vhdl|*verilog*>
    Specify RTL language to use for C/RTL co-simulation.
  -setup
    When this option is specified, all the simulation files will be created in the "sim/<HDL>" directory of the active
    solution, but the simulation will not be executed.
  -stable_axilite_update
    Enable axilite to config registers which is stable compared with previous transaction
  -stdmath [=true|*false*]
    Link the system standard math library
  -tool <vcs|questa|modelsim|riviera|xcelium|*xsim*>
    Option to select the HDL simulator to be used to co-simulate the RTL with the C testbench.
  -trace_level <all|port|port_hier|*none*>
    Determines the level of waveform tracing during C/RTL cosimulation.
  -user_stall <string> 
    Specify which ports to stall via a json file
  -wave_debug
    Opens the Vivado waveform viewer during co-simulation (simulation will not exit until the viewer is closed)
