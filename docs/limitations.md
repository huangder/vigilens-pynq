# 已知限制

截至 2026-11-02，当前仓库用于疲劳风险提示、状态趋势监测与实验室原型展示，不用于医疗诊断，不提供血氧或血压。

| 项目 | 当前边界与后续工作 |
|---|---|
| 最新持续版 SD 启动 | 已有构建/文件检查；独立断电启动、持续运行、物理相机恢复仍待实卡验收 |
| 完整 30 fps | 短测分析约 29.67 fps，存在跳帧；完整负载与抖动门限尚未通过 |
| 心率准确性 | 已输出候选，但缺同步参考与跨人群验证；5 秒窗和显示平滑不能作为精度依据 |
| 疲劳与行为准确性 | 眼嘴、姿态、质量阈值仍需针对当前 68 点路线标定，并用独立标注评估 |
| 连续显示 | 可显示历史数字并标明年龄；历史值不代表当前测量，也不进入告警 |
| 呼吸率、年龄与录像 | 板端 RR 尚未实现；PC 侧辅助功能不等于已部署到板端 |
| PL 参与范围 | 当前活动像素链为 ROI/灰度/运动量；额头 RGB 与心率滤波/频谱在 PS |
| 契约 | 生效版本与未会签候选并存，不能用当前参数替代正式会签记录 |
| 从零构建 | 脚本仍依赖本机工具链/Buildroot/模型路径；源码不是完整离线工具链镜像 |
| 权重与依赖 | 不分发模型、第三方源码缓存和大型启动产物；使用者须自行准备并核对授权 |

ERT 68 点模型的训练数据可能附带 iBUG 非商用条件，不能因为本仓库代码采用 MIT 就认为模型同样采用 MIT。当前 Git 提交不包含这些权重。其他库、模型与工具以各自许可为准。

完整验收应保留实际板型、配置/程序哈希、输入性质、命令、退出码与原始输出。旧板卡/旧固件日志只能证明对应版本的结果；详见 [验证与证据](validation.md)。
