```python
MODE = "matrix"
```

| 段 | 组 | 为什么先跑 |
|---|---|---|
| `small` | JPEG/QVGA×2、GRAYSCALE/QQVGA、RGB565/QQVGA | **JPEG 的真实压缩字节数**（A 线旁路画面的带宽预算就等它） |

| `big` | GRAYSCALE/VGA、JPEG/VGA×2、RGB565/VGA | 大的/已知会失败的放最后 |

**判据**：每段跑完有完整表格；**留意每组开跑前那行**
`---- [k/N] … 开始（此刻 gc.mem_free() = … B）----` 与紧随其后的 `⚠️ 内存余量：…`。
**若某组之后再无输出**：最后出现的那个组号**就是把它搞死的那一组**，
**恢复办法 = 拔掉 micro-USB 再插上**（真卡死时 PC 侧症状就是"连接没有响应"）。
