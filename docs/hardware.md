# 硬件与连接

当前实物为 MicroPhase Mizar-Z7 7020（Mizar-Z7020），器件 `xc7z020clg400-1`。板型历史及未会签参数见 [接口契约](interface.md)，使用其他板卡时须重新核对 PS 初始化、设备树、引脚、时钟与电源，不能直接套用本板产物。

| 项目 | 当前用途 |
|---|---|
| Mizar-Z7020 | PS 执行 Linux 与 C/C++ 算法，PL 执行像素处理 |
| USB UVC 摄像头 | 连接板卡 USB Host；交付候选为 640×480 YUYV、目标 30 fps |
| 有线以太网 | 浏览器访问板端 HTTP；默认静态地址来自 `config.yaml:cold_boot` |
| USB 串口 | 查看启动/服务日志；冷启动说明使用 115200、8N1 |
| 已分区 SD 卡 | 第一主分区 FAT32，保存完整同版启动文件和应用 |
| JTAG | 开发、加载与取证；独立冷启动验收不以 JTAG 补发初始化 |

摄像头档位必须以驱动实际协商结果与序号/时间戳确认；请求 30 fps 并不证明已得到 30 fps。720p MJPG 是历史实验档位，不能把旧报告直接套到当前 YUYV 候选。

供电、USB Host 接口位置、SD 启动拨码以实物板卡手册为准。旧 OpenMV、IMX219/MIPI 方案已取消，当前无需按旧采购清单接线。板端采用 Buildroot，PYNQ 脚本保留为可复用工具，不代表本板安装了 PYNQ。

SD 拷贝、校验、网络及服务检查按 [冷启动 README](../board/cold_boot/README.md) 执行。板端默认 `169.254.73.29/16`，PC 需配置可达网段；修改地址必须重新生成对应配置。物理验收状态见 [验证与证据](validation.md)。
