> 📌 **OpenMV 的内存天花板（2026-09-24 真机实测，比任何带宽算术都硬）**
>
> | 项 | 实测值 | 结论 |
> |---|---|---|
> | `gc.mem_free()`（启动时） | **308944 B** | H7 标称 1 MB SRAM，**留给帧缓冲的可用量只有 302 KB** |
> | 契约帧 640×480 **RGB888** | 需 **921600 B** | **是可用内存的 3.0 倍 → 装不下** |
> | 640×480 **RGB565** | 需 614400 B | **实测直接抛 `RuntimeError: Frame buffer overflow`** |
> | 640×480 **灰度** | 需 307200 B | **只差 1744 B** —— 擦边，能否成功**本次没测到** |
> | `RGB565 / QVGA` | **39.76 fps 均值**，153600 B/帧 | 帧率超契约 30 fps，但**像素只有契约的 1/4 且不是 RGB888** |
>
> **这是片上内存限制，与接哪个口（UART / USB / SPI）无关** —— 所以它比"带宽差 29 倍"更强：
> 带宽能换接口解决，内存不能。**换摄像头模块（MIPI CSI）才是唯一出路**，见 §4.3 与 `docs/10` §3/§12。

## 2. Mizar-Z7020 板卡规格

> 来源：MicroPhase 官方《[Mizar-Z7 Reference Manual](https://fpga-docs.microphase.cn/en/latest/DEV_BOARD/MIZAR-Z7/MIZAR-Z7_Reference_Manual.html)》。
> ⚠️ 厂商把产品叫 **Mizar-Z7**，分 **7010 / 7020** 两个版本；本项目用的 7020 版。
> **拿到板子请核对丝印**，确认是 7020 版（7010 版**没有** MIPI CSI / Wi-Fi / HDMI2）。

### 2.1 核心

| 项 | 值（7020 版） | 对比 7010 版 |
|---|---|---|
| **SoC** | **XC7Z020-1CLG400C** | XC7Z010-1CLG400C |
| 逻辑单元 | 85K | 28K |
| LUT | 53,200 | 17,600 |
| 触发器 | 106,400 | 35,200 |
| DSP Slice | 220 | 80 |
| Block RAM | 4.9 Mb | 2.1 Mb |
| **DDR3** | **1 GB**（两片 16-bit） | 512 MB |
| PS 主频 | 667 MHz 双核 Cortex-A9 | 同 |
| XADC | 2× 12-bit | 同 |

> ✅ **关键结论**：**XC7Z020-1CLG400C 与契约 §0 冻结的 `xc7z020clg400-1` 是同一颗器件**
> （`C` 只是商用温度等级后缀，Vivado 的 part 字符串相同）。
> 所以**四个 HLS IP 与全部黄金参考无需重做**，换板只影响**板级三件事**：
> PS 配置（DDR 1GB）、引脚约束、bitstream。

### 2.2 时钟

| 位置 | 信号 | 频率 | 引脚 | 用途 |
|---|---|---|---|---|
| Y1 | `PS_CLK_33d3` | **33.333 MHz** | **E7** | PS 系统时钟 |
| U19 | `PL_CLK_50M` | **50 MHz** | **H16** | PL 逻辑额外时钟 |

> ⚠️ **本项目的一个重要澄清**：契约 §3.5 的 **100 MHz 目标时钟来自 PS 的 FCLK0**
> （`board/build_bd.tcl` 里 `CONFIG.PCW_FPGA0_PERIPHERAL_FREQMHZ = 100`），
> 由 PS 的 33.333 MHz 经 PLL 产生，**与 PL 那颗 50 MHz 晶振无关**。
> H16 的 50 MHz 只在做**独立 PL 设计**（如 `pl_uart_echo.v`，不启 PS）时才用。

### 2.3 存储与配置

| 项 | 型号 / 规格 | 位置 |
|---|---|---|
| QSPI Flash | **W25Q256FVEI，256 Mbit**（Winbond） | U3 |
| eMMC | 8 GB | — |
| micro SD | 1 个卡槽（启动镜像 / 根文件系统） | — |
| 启动模式 | **JTAG / QSPI / SD**，由 **J1 的 MODE 跳线**决定 | J1 |
| 复位键 | **K1**（专用复位，给 PL 设计用） | K1 |

### 2.4 外设

| 外设 | 器件 / 规格 | 备注 |
|---|---|---|
| 以太网 | **RTL8211E**，RGMII 接 PS MAC | ⚠️ **手册自相矛盾**：Key Features 写 "1 10/100 Ethernet RJ45"，但 "Giga ETH" 节写 RTL8211E 支持 **10/100/1000**。**以 `ethtool eth0` 实测为准** |
| USB Host | **USB3320C-EZK**（ULPI，USB 2.0 高速） | 可插 OpenMV（CDC 设备 → `/dev/ttyACM0`） |
| USB Slave | USB 2.0 | — |
| **USB UART** | **CH340** | 接 PS 的 **MIO14/MIO15** —— 这是 **console**，不是空闲串口 |
| **USB JTAG** | 板载 JTAG 电路 | 下载/调试，**PL 首次上板走这条** |

| HDMI | HDMI1（可配为 RX）、HDMI2（**仅 7020**，可配为 TX） | ⚠️ 手册对收发方向措辞自相矛盾，待实测 |
| Wi-Fi / BT | 802.11b/g/n + BT 4.0 | **仅 7020 版**；默认陶瓷天线 |
| 按键 | 6 个（2 个 PS + 4 个 PL），**按下为低** | 见 §3.2 |
| LED | 6 个（2 个 PS + 4 个 PL），**低电平点亮** | 见 §3.2 |

### 3.4 扩展口电平与电压调节（**上电前必查**）

- 48 个 IO **电压可调**，出厂默认 **3.3V**；由 **BANK34 的 VCCIO** 决定，
  用 **R208 / R209 / R210** 三个 0 欧电阻选择，**只能焊一个**：

  | 电阻 | BANK34 电压 | IO 电压 |
  |---|---|---|
  | **R208** | 3.3V | **3.3V（出厂默认）** |
  | R209 | 2.5V | 2.5V |
  | R210 | 1.8V | 1.8V |

- **本项目要用 3.3V**（OpenMV 的 IO 是 3.3V 输出、5V 容忍）→ **确认 R208 在位、R209/R210 不在位**。
- **用万用表实测** JP2 pin 29（VCC_3V3）与 pin 11（VCC_5V）区分开。

> ⛔ **绝对不要把 JP2/J P1 的 pin 11（VCC_5V）接到任何 3.3V 逻辑引脚上。**

## 4. 三种工作模式的接线

### 4.0 总览

```
模式 ①  纯软件（现在就能做，不需要任何硬件）
   笔记本 ──► A 线算法 ──► B 线网页

模式 ②  OpenMV 接入（需要 OpenMV）
   ①-a  UVC 模式：  OpenMV ──USB──► 笔记本 ──► A 线 ──► 网页（**零代码**）
   ①-b  串口模式：  OpenMV P4/P5 ──USB-TTL──► 笔记本

模式 ③  上板（需要 bitstream）
   ③-a  最小上板：OpenMV ──UART(3 线)──► Mizar JP2 (PL)   ← 不需要 PS/DDR
   ③-b  完整链路：MIPI 摄像头 ──FPC──► Mizar (PL) ──► 笔记本
```

### 4.1 模式 ①：纯软件（✅ 现在就能做）

```powershell
# 先载入会话环境（切到仓库根 + 把 .venv 排到 PATH 最前）
. .\env.ps1

python metrics/scripts/check_all.py          # 总回归
python metrics/scripts/run_demo.py           # 一键演示（合成帧源）
```
**接线：无。** 见 `docs/11` 的 L0~L4。

### 4.2 模式 ②：OpenMV 接入（⚠️ 待硬件）

#### ②-a UVC 模式（推荐，零代码）

1. 用 OpenMV IDE 给摄像头刷 **`uvc.bin`** 固件 → OpenMV 变成标准 UVC 摄像头；
2. micro-USB **数据线**接笔记本；
3. `python metrics/scripts/run_demo.py --list` 找序号 → `python metrics/scripts/run_demo.py --source 0`
   （把 `0` 换成上一步打印的实际序号；**别照抄尖括号占位符** —— PowerShell 里 `<>` 是保留运算符）。

> ⚠️ **`uvc.bin` 会替换固件** —— 刷了它就跑不了 `openmv_stream.py` / `openmv_capture_test.py`
> 那些 MicroPython 脚本；要回去跑脚本得重刷 `firmware.bin`。**两者不可兼得。**

#### ②-b 串口模式

```
OpenMV P4 (UART3 TX) ──► USB-TTL 的 RX
OpenMV P5 (UART3 RX) ◄── USB-TTL 的 TX
OpenMV GND           ─── USB-TTL 的 GND      ← 必须共地
```
需要 `pip install pyserial`。

### 4.3 模式 ③-a：PL 最小上板（⚠️ 待硬件；**先做这个，不需要 PS/DDR**）

**接线（只有 3 根信号线 + 共地）**：

```
       OpenMV Cam H7                          Mizar-Z7  JP2
    ┌───────────────┐                     ┌──────────────────────┐
    │  P4 (UART3 TX)├────────────────────►│ pin 5   K14  uart_rx │
    │  P5 (UART3 RX)◄────────────────────┤ pin 7   H15  uart_tx │
    │  GND          ├────────────────────┤ pin 12  GND          │
    │               │                     │                      │
    │ (可选) 任一输入脚 ◄─────────────────┤ pin 3   G17  clk_test│ ← 1 kHz 方波
    └───────────────┘                     └──────────────────────┘
       USB 单独供电                          +5V DC + USB-JTAG
```

**上电前必查 5 条**：
1. ☑ **共地**（JP2 pin 12 ↔ OpenMV GND）—— 不共地是"完全收不到数据"的头号原因
2. ☑ **TX/RX 交叉**：OpenMV 的 TX 接板子的 `uart_rx`(K14)，**不要 TX 接 TX**
3. ☑ **电平**：两边都 3.3V，**直连、不需要电平转换**；但要先确认 R208 在位（§3.4）
4. ☑ **绝不接 pin 11（VCC_5V）**
5. ☑ **先不要用板子的 3V3 给 OpenMV 供电** —— 让它用自己的 USB，少一个变量

**约束文件**：`board/openmv/mizar_z7_openmv_uart.xdc`
**设计文件**：`board/openmv/pl_uart_echo.v`
**测法**：`docs/11` 的 L8。

### 4.4 模式 ③-b：完整链路（⚠️ 需先采购摄像头）

```
树莓派摄像头 ──15-pin FPC 排线──► Mizar MIPI CSI 口 ──► PL(CSI-2 RX → demosaic → 本项目四个 IP)
                                                              │
                                                        PS ────┴──► 笔记本 ──► 网页
```

⚠️ **这条路的两个真实成本**（详见 `docs/10` §12.4）：
① 相机输出 **RAW10 Bayer，不是 RGB** → PL 要新增 **demosaic IP**；
② 云台已搁置，所以"追踪/测量互斥"的问题**暂时不用管**。

## 5. 电源与供电

| 项 | 规格 | 注意 |
|---|---|---|
| 板卡主供电 | **+5V DC 圆孔** | ⚠️ **不能用 micro-USB 供电** —— 很多板子 USB 供电不足以让 PL 起来 |
| 扩展口输出 | JP1/JP2 有 **VCC_5V**（pin 11）与 **VCC_3V3**（pin 29） | ⛔ VCC_5V 不要接 3.3V 逻辑脚 |
| OpenMV 供电 | 自己的 micro-USB | 活动约 **160~170 mA @3.3V**（官方规格） |
| 云台舵机 | **【已搁置】** 若复活：**必须独立供电**，不得与板卡 3V3 共用 | 堵转电流远大于逻辑电源 |

## 6. 摄像头

**完整选型建议见 `docs/10_架构评审_采集分工与追踪闭环.md` §12**（判据、推荐清单、
RAW Bayer 成本、采购踩坑、推进顺序）。这里只放结论：

| 推荐度 | 型号 | 传感器 | 接口 | 关键点 |
|---|---|---|---|---|
| 🥇 先用这个 | **Camera Module 2**（**15-pin**） | IMX219 | 2-lane MIPI | 最便宜、例程最多；640×480 能到约 100fps |
| 🥈 云台复活后 | Camera Module 3（15-pin） | IMX708 | 2-lane（可 4） | **PDAF 自动对焦** |
| 🥉 可换镜头 | HQ Camera | IMX477 | 4-lane（15-pin 下走 2-lane） | 可换 C/CS 或 M12 镜头；**重** |
| ⚠️ 特殊 | Global Shutter Camera | IMX296 | 2-lane | 全局快门，但**黑白** → 破坏契约 RGB888 |

**三条采购硬注意**：
1. **买 15-pin 1 mm 版**，不要买 Pi Zero 的窄排线版；
2. Mizar 是 **top-contact** FPC，**插反不工作**；
3. **不要随意加长 MIPI 排线**（D-PHY 高速差分，加长/劣质排线会误码）。

## 7. 未核实 / 待实测清单（**上板前逐条打勾**）

| # | 项 | 怎么核 | 影响 |
|---|---|---|---|
| 1 | 板子实物是 **7020 版**（不是 7010） | 看丝印 / 看芯片型号 | 7010 没有 MIPI CSI / Wi-Fi / HDMI2 |
| 2 | 芯片是 **XC7Z020-1CLG400C** | 看芯片丝印 | 与契约冻结的 `xc7z020clg400-1` 是否同一颗 |
| 3 | **R208 在位、R209/R210 不在位**（VCCIO34 = 3.3V） | 万用表量 JP2 pin 29 / pin 11；看电阻位 | IO 电平错 → 外设通信乱码或损坏 |
| 4 | 启动模式跳线 **J1** 按手册设对 | 对照手册 BOOTMODE 图 | 模式错 → 板子完全没反应 |
| 5 | **以太网实际速率** | `ethtool eth0` | 手册自相矛盾（10/100 vs 10/100/1000） |
| 6 | **HDMI1 / HDMI2 的收发方向** | 实测 | 手册措辞自相矛盾 |
| 7 | **Mizar 是否提供 Vivado board file** | `get_board_parts` in Vivado | 没有 ⇒ PS7 的 **1GB DDR 参数必须取自厂商参考设计，不得猜** |
| 8 | **板上有没有 PYNQ 环境** | `python3 -c "import pynq"` | 没有 ⇒ `load_overlay.py` 的 PYNQ 路线不可用，M3 改走 `/dev/mem` mmap |
| 9 | **MIPI CSI 口是否提供 3.3V / I2C / MCLK** | 万用表 + 查原理图 | 官方说引脚兼容树莓派，但仍需确认 |
| 10 | USB Host 能否给 OpenMV 足够电流 | 插上看是否掉电重启 | 不稳就给 OpenMV 单独供电 |
