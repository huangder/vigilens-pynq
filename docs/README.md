## 5. 诚实边界

- 本索引**不替代**任何一份文档；它只回答"该读哪份"。
- 每份文档里的"✅ 完成"是**维护者的声明**，可能滞后。**代码是否真的实现了某功能，只以三样为准**：
  源码可读到的实现 + 测试是否覆盖 + 真实运行输出（`AGENTS.md` §8）。
- 归档文档里的数字是**当时的真实运行**，不是今天的承诺；引用前先看它自己的"诚实边界"一节。
- 文档与代码冲突时的处理顺序：**先确认哪个对（跑命令）→ 同一提交里把两边改成一致**，而不是只改一边（`AGENTS.md` §3）。
