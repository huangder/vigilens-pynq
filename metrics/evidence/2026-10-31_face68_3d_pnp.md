# 2026-10-31 68 点 3D 参考与 PnP 姿态

为 `docs/55` 留下的「68 点没有 3D 参考、PnP 未做」补一套**有出处、可复现**的参考模型，
并在真实片段上与 2D 几何、MediaPipe 姿态分别对照。

## 1. 3D 参考是怎么来的

`board/autonomy/build_face68_model.py`（本机运行，不外传任何画面）：

1. 用 MediaPipe FaceMesh 取 468 个带 `(x, y, z)` 的关键点；
2. 只保留姿态接近正面的帧（`|yaw|<15°`、`|pitch|<10°`），共 **76 帧**；
3. 每帧按「双眼六个轮廓点的均值 → 中心，两中心距离 → IOD」归一化，再对每点取中位数；
4. 把 68 个 Peppa 点映射到最近的 468 点（同一归一化 2D 空间），记录逐点残差；
5. **X/Y 用 68 点自己的正面中位布局，Z 用映射到的 MediaPipe 深度**——
   正面模型与检测器自身的 2D 布局一致，深度只提供前后关系。

关键修正：MediaPipe 侧一开始用的是「外眼角 33/263」，与 Peppa 的「眼轮廓质心」不是同一把尺，
导致映射整体错位约 15% IOD；改成同一把尺后残差从 0.20 IOD 降到 **0.07 IOD**。

产物：`board/autonomy/face68_3d.json`
（`points_68` 68×3，单位 = IOD；`mapping_to_mediapipe`；逐点残差）。

**不是**解剖学平均脸、**不是**米制深度；它是该素材受试者的均值参考。

映射抽查：30→1（鼻尖）、8→152（下巴）、36→33、39→155、45→249、48→43、54→335；
逐点残差中位 0.06、均值 0.07、最大 0.32 IOD（下巴附近，属两套模型的形状差）。

## 2. 求解

`board/autonomy/peppa_geometry.py::solve_pose_pnp`：

- `cv2.solvePnP`（EPNP + ITERATIVE 两支，取重投影最小且 `tvec.z>0` 的解）；
- 相机 `f = 图像宽`、主点在中心，与 `backend/face_landmark` 一致；
- 角度分解与后端**同一公式**（`yaw=atan2(-R20,·)`、`pitch=atan2(R21,R22)`、`roll=atan2(R10,R00)`）；
- 平均重投影误差 / IOD 超过 `config.yaml: pose_reproj_max_frac = 0.25` 或解退化 → 返回 `None`，不补角。

## 3. 验证【已验证】

| 项 | 结果 |
|---|---|
| 合成回环（45 组 yaw/pitch/roll，±20°/±10°/±15°） | 解算误差 **0.00°**（三个角全部） |
| 实测可解帧 | **604 / 621**（17 帧退化或超门限被拒） |
| 重投影误差 | 中位 **3.87 px**、p95 10.47 px；比值中位 0.041、p95 0.123（门限 0.25） |
| yaw 与「鼻尖水平偏移/IOD」 | r = **−0.916**（符号与旋转约定一致） |
| roll 与 2D 眼线角 | r = **0.938** |
| pitch 与「鼻尖垂直偏移」 | r = 0.141（弱相关，俯仰最不敏感，不足以单独当验收） |

## 4. 与 MediaPipe 姿态的差异（必须如实写）

同一批 604 帧：

| 角 | MediaPipe 中位 | PnP 中位 | 中位绝对差 | 相关 |
|---|---:|---:|---:|---:|
| yaw | **−22.5°** | **+1.5°** | 26.3° | 0.70 |
| pitch | 2.6° | −2.4° | 3.5° | 0.64 |
| roll | −0.4° | −0.7° | 1.4° | 0.59 |

判定哪一侧更可信的两条独立证据：

1. **MediaPipe 自己不一致**：用 MediaPipe 的 468 点网格做 PnP（模型也来自该网格），
   632 帧的 yaw 中位是 **−0.03°**，而它的六点 `face.pose` 给 **−22.53°**；
2. **2D 鼻尖偏移**中位只有 0.025 IOD（≈2 px）；若真转 22°，鼻尖应偏 ~0.19 IOD。

因此本片段的 MediaPipe yaw 更像已知的六点平面模型偏置，**PnP 的 yaw≈0 更符合几何**。
但这**不是** PnP 的准确率证明：没有人工头部姿态真值。

## 5. 对契约链路的影响

`pc_autonomy_demo.py` 的 `--pose pnp` 已成为默认（`pose_migrated=true`），
同一段 656 帧：

| 姿态来源 | `normal` | `adjust_posture` |
|---|---:|---:|
| MediaPipe（替身） | 510 | 145 |
| **68 点 PnP** | **603** | **52** |

契约仍 **655/655 合法**。52 帧里 35 帧是几何退化（`visible=0`），其余是 PnP 角度越界。

## 边界

- 模型是**该素材受试者**的均值脸；换人应重新生成或改用通用模型，不能宣称跨人泛化。
- 没有真人头姿真值；只有合成回环、2D 几何一致性和 MP 自洽性三类证据。
- PnP 目前是 **Python/PC** 实现；板端 C 还没有 PnP，板端自治的 `face.pose` 仍待移植。
